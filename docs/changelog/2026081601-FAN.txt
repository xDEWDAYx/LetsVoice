本次改动修复了新建或打开工作空间后，Workspace 详情页在加载完成时立即崩溃
的问题，并增加页面级回归测试，锁定 WorkspacePage 与 useWorkspaceDetail 之间

preload、IPC、数据库、文件系统或平台专属代码。

1. 【工作空间详情】修复新建和打开工作空间时的 undefined.length 崩溃
------------------------------------------------------------------------
问题：
  - 在工作空间列表中新建工作空间，跳转到详情页后显示 React 错误覆盖层。
  - 点击打开已有工作空间时出现同样错误。
  - 错误信息为：
      TypeError: Cannot read properties of undefined (reading 'length')

原因：
  - useWorkspaceDetail 返回过滤后的笔记字段 visibleNotes。
  - languageUpdate 提交在 WorkspacePage 中把调用方改成了 filteredNotes，
    但没有同步修改 Hook 的返回字段。
  - 页面加载完成后执行 filteredNotes.length；由于该字段不存在，实际等价于
    undefined.length，因此空工作空间和已有工作空间都会崩溃。
  - 同一段页面改动还解构了 Hook 未提供且未使用的 setSemanticResults 与
    handleDeleteSelected，TypeScript 可以直接检出这些契约错误。

现在：
  - WorkspacePage 恢复读取 Hook 正式返回的 visibleNotes。
  - 空状态判断使用 visibleNotes.length。
  - 笔记列表使用 visibleNotes.map。
  - 删除无效的 setSemanticResults / handleDeleteSelected 解构。
  - 清理同批遗留的 useLocation、Trash2、MessagesSquare 无用导入。

涉及文件：
  src/renderer/pages/Workspace/WorkspacePage.tsx
