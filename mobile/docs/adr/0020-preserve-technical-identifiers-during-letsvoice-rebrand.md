# Preserve technical identifiers during the LetsVoice rebrand

The product brand and every user-facing product name are standardised as `LetsVoice`, while existing lowercase technical identifiers such as the iOS bundle identifier, URL scheme, database filename, notification identifiers, and repository/package names remain unchanged. Preserving these identifiers keeps the renamed app on the existing iOS upgrade path and avoids breaking deep links or access to on-device user data.
